# ⚖️ MacroCount

MacroCount è un'applicazione web e desktop progettata per trovare gli alimenti ideali in base a specifici target di macronutrienti (Proteine, Carboidrati, Grassi).

## 🚀 Caratteristiche Principali

- **🎯 Target di Macronutriente**: Inserisci i grammi desiderati di proteine, carboidrati o grassi per calcolare la porzione esatta di ciascun alimento.
- **⚡ Ordinamento Intelligente per KCAL (o Grammatura)**: Ordina i risultati dal più leggero caloricamente al più denso per raggiungere il tuo obiettivo nutrizionale.
- **🔍 Filtri Secondari**: Imposta tetti massimi (es. max carboidrati o max grassi) nella porzione calcolata.
- **🚫 Esclusione Intolleranze & Allergeni**: Filtra per glutine, lattosio, frutta a guscio, uova, soia, pesce.
- **🌱 Regimi Alimentari**: Supporto per diete Vegane e Vegetariane.
- **📊 Indice Glicemico (IG)**: Indicazione visiva dell'impatto glicemico per ogni alimento con badge a colori (Basso, Medio, Alto).
- **🥦 Database di oltre 60 Alimenti**: Ampio database integrato con possibilità di aggiungere e rimuovere cibi personalizzati salvati in locale (`localStorage`).

## 💻 Come Avviarlo in Locale

### Opzione 1: Doppio Clic (Senza installare nulla)
Fai semplicemente doppio clic sul file `index.html` per aprirlo direttamente nel tuo browser preferito.

### Opzione 2: Con Server Locale / Desktop
1. Fai doppio clic su `start.bat`.
2. Scegli `1` per la finestra desktop nativa o `2` per il browser web.

### Opzione 3: Dal seguente link:
https://eldiabloma.github.io/MacroCount/
