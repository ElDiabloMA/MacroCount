# MacroCount

MacroCount è un'applicazione web e desktop progettata per trovare gli alimenti ideali in base a specifici target di macronutrienti (Proteine, Carboidrati, Grassi).

## Caratteristiche Principali

A differenza di tutte le altre APP sulle calorie e gli alimenti che generalmente partono dalla ricerca di un alimento e ne tirano fuori la composizione in macronutrienti, questa si pone lo scopo contrario: partire da una o più macronutrienti desiderati e proporre quale alimneto li contiene.
Utilissimo se devi comporre una dieta o trovare degli alimenti sostitutivi.
Puoi integrare a tuo piacimento la lsita degli alimenti presente.

## Come Avviarlo in Locale

### Opzione 1: Doppio Clic (Senza installare nulla)
Fai semplicemente doppio clic sul file `index.html` per aprirlo direttamente nel tuo browser preferito.

### Opzione 2: Con Server Locale / Desktop
1. Fai doppio clic su `start.bat`.
2. Scegli `1` per la finestra desktop nativa o `2` per il browser web.

### Opzione 3: Dal seguente link:
https://eldiabloma.github.io/MacroCount/

## Tecnologie Utilizzate
- **Frontend**: HTML5, Vanilla CSS (Dark Mode & Glassmorphism), JavaScript moderno (ES6+).
- **Backend/Desktop**: Python 3 con `pywebview` e server HTTP integrato.
